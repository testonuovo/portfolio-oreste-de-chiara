Progetto: Oreste AI

JavaScript (Vanilla) Web Speech API Browser Ecosystem Accessibility

Sviluppato interamente in JavaScript puro senza dipendenze esterne gravose, è stato ideato per offrire un'interfaccia accessibile e fluida anche in ambienti digitali complessi o a basse risorse hardware.
